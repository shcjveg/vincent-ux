# 视觉原则

管「看起来怎样」：层级、颜色、文字、立体感、图标。交互行为见 `interaction.md`，文案见 `content.md`。

## 层级靠面，不靠线

- 四级面，每升一级亮一档：画布 `surface-canvas` → 承载区 `surface-shell` → 卡片 `surface-card` → 浮层 `surface-overlay`。暗色下同样是越上层越亮。
- 嵌套用相对明度：子块比父面深一档（凹，如输入框、分段控件、次按钮用 `surface-inset`）或浅一档（凸，如卡片）。结构不靠描边。
- 分组靠留白和小标题，间距按下方场景表使用；同组近、不同组远。
- 结构分隔按需用 `line-faint`，用于长列表、数据表格和暗色相邻面。输入、选择、勾选等控件用 `line-control` 保证可辨识；校验错误、选中状态可用对应语义边框。
- 键盘焦点环使用 `focus-ring`，与错误／选中边框分离，始终保留。

## 安静的外壳，内容是主角

- 外壳（导航、页签、工具栏）只用文字和图标，不用色块；空状态的页面宁可留白，不用插画和装饰填满。
- 输入是一块独立的凹面：附属操作（附件、模型、语音）作为图标沉在它的底边一行，发送是其中唯一的实心按钮；上下文（带上的页面、选中的对象）以可删除的小块贴在输入区上沿。
- 次要工具按钮平时是无底的图标，悬停才出现一档填充。

## 颜色只表达意义

- 中性层（面、文字、填充）承担全部结构；品牌层只有两种强调：`brand-accent`（钱、选中、等你动手的那一个状态）和 `brand-critical`（红点、亏损、阻断、已超时）。这是全系统颜色语义的唯一出处，模式和组件只引用不重述。使用方页面不直接引用品牌色：在元素上用 `data-tone="accent | critical"` 声明语气，样式里取 `--vx-tone` / `--vx-tone-soft`；`scripts/audit.js` 会检查强调色和危急色是否都有合法出处。
- 决策动作的同意与中止可用少量语义色：同意引用 `data-positive`，中止引用 `critical`，同时配含义明确的图标与文字；仅落文字和图标，背景保持中性。
- 主按钮用墨色 `ink-base`，不用品牌色。
- 淡底色（`brand-accent-soft`、`brand-critical-soft`）只用于状态，淡到能分辨即可，不铺大面积。
- 状态优先写进必要说明。时限需要成为视觉重点时用墨色加粗（`.vx-due`），不用危急色；已通过标题或分组表达紧急程度时，时限保持普通文字。普通状态标签一律中性，并只在确有独立信息时使用。
- 不用彩色左边条、装饰性色块和装饰性描边。描边用于控件辨识、校验、键盘焦点和白卡选中状态。独立选择卡用淡底与细边界，不叠加复选框或装饰对号；图标与字重不随选中变化。需要分别表达打开与选择时，使用真实复选框。
- 提示条（`.vx-callout`）只放一句话的全页级提醒；一组对象各自有状态时，用卡片与列表行，必要时带一个简短状态；不重复正文已有的状态，也不把整组铺在一大块淡色底上。
- 图表：单序列用中性灰 `viz-neutral`，只把要你看的那段标成强调色；成片的柱和面积用强调色的淡化版（`.vx-spark`、`.vx-bar` 已内置），细线和小点才用实色。多序列才用 `viz-series-*`。

## 文字三级

- 标题 `text-primary`，正文 `text-secondary`，辅助 `text-tertiary`；导航内低优先级的空状态提示用 `text-muted`，仅在 shell 或 card 上使用，保持小字 4.5:1；业务内容空状态沿用 `EmptyState` 的正文字号与辅助文字色。层级先靠字色和字重，再靠字号。
- 同一个内容区域通常使用三档字号；仪表指标、页标题可有独立展示字号。字号只取 `font-size-*` 刻度。
- 字体用系统字体：桌面应用要求零网络、启动快，中文系统字体排版最稳。字体上的个性只放在数字上：金额、百分比、件数的大号展示用 `font-family-num`，并开启等宽数字。

## 组件内控制样式种类

一个常规行组件默认只有两层文字：**主标题**（14px、半粗、主文字色）和**必要说明**（13px、常规、次文字色）。行尾数量与操作沿用说明层，不再引入独立数字字体、第三种灰色或额外字号。整页可以有页面标题，单个组件不必用满系统所有文字档位。

- **一个重点**：标题说清对象与要做的事。类型、渠道、时限合成一句必要说明；避免每个词各做一个标签、各用一档字重。
- **一次状态表达**：正文已经说“缺少报告，暂不能上架”，就不再叠“卡住上架”红色胶囊。确需快速扫描的状态可单独呈现，但移除重复文案。
- **一个操作出口**：整行可点时，末尾一个方向图标即可；折叠行用数量与箭头，展开状态由 `aria-expanded` 表达，操作文字保留给读屏。不再同时显示计数、展开文字和重复状态图标。
- **一个承载面**：已有卡片时，展开的说明直接排版，不再套凹面或另一张卡。通过对齐、组内 4px 的标题／说明距离和组间留白分层。
- **一个额外强调上限作为默认**：只有确需处理的异常才增加语义色；必要的错误提示、键盘焦点独立保留。键盘焦点跟随控件圆角，不能为了安静而隐藏。

这是一组默认约束，复杂的数据比较仍应选表格，而不是在一张卡内继续增加样式。示例见展示页“分子”的待办行与展开行。

## 立体感用最轻的手段

- 基础面用实色明度差；卡片只在必要时加 `shadow-card`。
- 只有浮层用 `blur-overlay` 磨砂玻璃和 `shadow-overlay`：对话面板、下拉、提示、导览说明卡、悬浮入口。
- 不用渐变铺底；主按钮的墨色渐变是唯一例外，用来给它一点手感。

## 图标必须有功能含义

- 图标表达「这一项是做什么的」，按 `icons/` 的含义对照表选，不按好看选。
- 禁用没有含义的装饰图标（星星、魔法棒、闪光），按钮和入口也不用。
- 纯图标按钮必须带文字标签（可见或给读屏）。

## 刻度与例外

颜色、字号、间距、圆角、阴影优先引用变量。间距包括 4px 主刻度与 2px 半阶；微小控件内部可用半阶。1px 边框、图标几何、容器断点、百分比和动态测量不强行变成 token；独立的视觉校正需要有具体理由。新增变量应是可复用的语义或刻度，避免为单个页面造名字。

## 布局与间距

### 容器位置不随 item 数量跳变

**容器的位置默认由父布局和固定锚点决定，内部 item 的数量只影响内容排布与可用高度。** 框架锚点根据任务与视口确定：欢迎说明可以整体平衡，分步选择保持外框稳定，工作页面从顶部展开；具体组合见 [页面框架](../patterns/page-composition.md#按任务选择视口框架)。 增删、筛选、加载或切换步骤时，不因内容变少重新居中，也不让首项或选中项反过来决定外框位置。

- 普通列表、网格、卡片与分步引导正文从各自框架的固定顶部起点向下排；网格列数由可用宽度决定，少量结果仍从首列开始。
- 弹窗固定顶部偏移并水平居中，正文向下增长，超出视口时内部滚动；抽屉固定上下边缘。下拉固定对齐触发器的起始边，不按选中项序号移动外框。
- 明确贴底的容器保持底边锚定，可向上增长。导览说明卡优先保留当前停靠位置，但不能遮挡正在介绍的功能：先保证目标完整，再由说明卡避让。只有视口、目标位置或避让需求改变时才调整锚点；不能因为 item 数量变化重新选择对齐方式。
- 加载、空、失败与有结果共用同一内容区域，标题和工具栏保留在原处。需要分页器或相邻工作区也稳定时，由父布局预留内容高度并在内部滚动；普通文档流中的后续内容可以随前方内容自然下移，无需给每张卡强加固定高度。

验收时在同一视口、同一滚动位置依次放入 0、1、多项及长内容：检查约定的顶部／底部／触发器锚点不变，内容可完整访问，不能用位移动画掩盖重新定位。

### 默认间距

采用 4px 主刻度，下面是默认值，不需要再为每个页面设计一套密度。相关内容聚拢，独立区块留得更开；“透气”来自层次和对齐，不是把所有间距一起放大。

| 场景 | 默认值 | 对应实现 |
|---|---|---|
| 标题与简短说明 | 4–8px | `space-1 / 1-5 / 2`；列表标题与元信息可紧凑至 2px |
| 字段标签、输入、帮助文字 | 6px | `.vx-field`；字段之间另留 16px |
| 图标与文字、同组按钮 | 8px | `.vx-cluster`、按钮与动作区 |
| 筛选控件、筛选条件换行 | 12px | `.vx-filterbar` / `.vx-filter-panel` |
| 纵向内容组、表单字段、并排网格 | 16px | `.vx-stack`、`.vx-grid` |
| 标准卡片内边距 | 20px | `.vx-card--padded`，或 `.vx-card-head` + `.vx-card-body` |
| 浏览网格 | 卡片内 20px、卡片间 16px、内部组间 12px | `.vx-browse-grid` |
| 内容列表 | 每项内 16px、项间 12px | `.vx-browse-list`；卡片内部普通 `.vx-row` 上下各 10px |
| 独立区块之间 | 24px | `.vx-stack--lg`、`.vx-page` |
| 页面外缘 | 顶部 24px、左右 32px；窄内容区左右 16px | `.vx-page`，底部另给悬浮操作预留空间 |
| 弹窗／抽屉 | 外缘 20px、标题到正文 16px、正文到动作 24px | `.vx-overlay-head/body/foot`，各段边距合计 |

**组合时只由一处负责间距。** 兄弟之间优先由父容器 `gap` 控制；组件负责内部 padding。不要在已有 gap 上再叠上下 margin。卡片只选 padded 或 head/body 一种结构，避免双重内边距。浮层各段左右对齐；字段标题、输入和说明共用左边线。

文字使用正常或宽松行高（`font-leading-normal` / `relaxed`），多行内容自然增长。窄窗口先换行、减少列数、缩减页面外缘，不压缩字号、命中区或卡片内边距来硬塞。表格、导航等高密度控件可保留紧凑尺寸，但不把它们的间距套到整页内容。

视觉验收：用真实长度的标题、两三行摘要、错误说明和多行条件查看页面；检查相邻控件不碰撞、同组对齐、组间清楚、文字不贴边。至少检查浅深主题和 1024px 窗口。刻度检查通过只说明用了合法数值，不能代替这一步。

导览说明卡、蒙层和目标边界共用系统浮层与中性边界变量；键盘焦点保持独立。组合约定见 [功能导览](../patterns/guide.md)。
