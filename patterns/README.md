# 交互模式

模式管「多个组件怎么配合完成一类交互」。组件管外观和自身交互，模板只管骨架。覆盖人和 AI 分工、导航与内容浏览。具体产品的功能流程（比如某个应用怎么用）不放这里，放在各产品自己的需求文档里。人只在关键节点确认、判断、指方向，上下文整备与执行交给自动规则或 AI。

| [页面组合](page-composition.md) | 组件放回真实页面后，如何控制阅读顺序、密度、承载层次与响应布局 |
| [关键节点拍板](decision.md) | 需要人判断时，信息怎么递给他 |
| [待办与红点](todo-and-badge.md) | 所有要人处理的事怎么汇总、怎么提醒 |
| [谁做的](actor-mark.md) | 自动完成和 AI 完成的事怎么标、怎么不打扰 |
| [写操作三级](write-levels.md) | AI 能自己动手到什么程度 |
| [带上下文派活](delegate.md) | 人怎么把一件事交给 AI |
| [页面与对话双向流转](page-chat-flow.md) | 会话、页签与业务状态如何归属；关闭、恢复、定位与焦点如何衔接 |
| [导航围绕任务](nav-overflow.md) | 主入口怎样降低理解门槛，专业工具怎样按需出现 |
