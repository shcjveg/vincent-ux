# 页面与对话双向流转

稳定流程由图形页面承载，灵活需求通过对话展开；两者使用同一对象与修订记录。外壳三栏按需出现，引导可以只留当前必要面板。

## 状态归属

| 范围 | 保留什么 | 谁负责 |
|---|---|---|
| 会话 | 消息、输入草稿、右侧开关、页签集合与当前页签 | 宿主按会话 ID 保存 |
| 页签实例 | 页面参数、筛选、未提交输入、展开项与滚动位置 | 页面自身状态；稳定实例 ID |
| 业务对象 | 已提交数据、待办及历史快照、修订与执行回执 | 共享业务层；切换会话仍一致 |

切换会话恢复该会话自己的页签、当前页及开关；每个页面读取自身上下文，隐藏页不能被当前页参数覆盖。临时导航随该页签集合变化，打开页面不自动置顶。

## 关闭、恢复与焦点

- 单页签关闭移除该实例；关闭非当前项保持当前页，关闭当前项选择邻页。最后一页的落点由产品明确。
- 整体关闭右侧使用页签栏右上角的轻量关闭图标，保留所有页签及状态；对话占满剩余空间，消息与输入保持有上限的阅读宽度。
- 对话头部使用 `open-workspace` 图标恢复右侧。主动从导航或对话打开页面时展开右侧，并按明确传入的对象范围定位。
- 收起对话保留消息与草稿，焦点恢复到可见入口；若它是最后一个可见主面板，应恢复页面或显示明确起始入口，避免留下无法操作的空壳。
- 手机单面板仍有导航入口；覆盖导航优先消费 Esc，关闭后回到当前可见入口，不连带关闭底层对话。覆盖对话跳到页面后展示落点。

没有会话时可以保留独立工作台；若产品选择在关闭右侧时建立会话，应将原页签实例完整归入新会话，保留已有输入。会话创建时机、存储介质与跨刷新恢复范围属于产品契约。

## 双向流转

页面发起讨论时携带对象、依据与当前选择，见[带上下文派活](delegate.md)。对话打开页面时进入当前会话的页签组并定位对象；需要用户给 AI 确认或修改反馈时，定位同一待办实例，不在会话另外复制确认控件。确认与人工分流更新共享实例，外部执行回执独立跟进，见[待办工作页](task-workspace.md)。

## 接入与检查

`Tabs variant="workspace" keepMounted` 保留各页签实例，`hidden` 隐藏整组；稳定 key 防止恢复时重新创建页面。`actions` 放整体关闭，`.vx-app[data-render="closed"]` 让对话填满。若页面很多，可由宿主卸载并显式保存／恢复状态；隐藏不等于暂停请求或副作用，订阅和资源释放仍由宿主管理。相同 ID 的页签刷新业务数据时不重置用户输入。

示例：[WorkspaceDemo](../showcase/WorkspaceDemo.tsx)。验收切换两个会话、编辑输入、切换页签、关闭／恢复、滚动与手机导航；隐藏面板不在键盘路径中，自动化定位只检查当前可见页。业务版本校验与持久化由使用方另测。
