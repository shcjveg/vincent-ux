# 页面与对话双向流转

**解决什么**：稳定的流程适合图形页面，灵活的长尾需求适合对话；两者要能互相接上，不能各管各的。

**规则**
- 外壳三栏按需出现：左栏可收起；中栏对话默认关闭，由人唤起；右栏是浏览器式页签。引导阶段只显示右栏。
- 页签属于对话：每个对话有自己的一组页签，切换对话即切换页签；不在任何对话里时是「工作台」这一组。
- 页面 → 对话：见 `delegate.md`。
- 对话 → 页面：AI 回复里的「打开页面」在当前对话的页签组里新开或切到对应页签，并定位到对象。
- 拍板 → 执行：在页面上确认一个决定后，若对话开着，对话里出现「按你的决定开始执行」的步骤，执行完回报。

**用到的组件**：`.vx-app`、`.vx-nav`、`.vx-chat`、`.vx-tabs`、`.vx-steps`
