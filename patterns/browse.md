# 内容浏览与筛选

用于资料库、内容库、商品或任务集合。按「查找 → 缩小范围 → 看结果 → 打开或选择」组织，保持一套结果和状态。

| 区域 | 组件与规则 |
|---|---|
| 查找 | `SearchField` 有明确名称和清空动作；本地数据即时筛选，远程请求可防抖或 Enter 提交 |
| 条件 | `FilterBar` 放常用 `Select` 或少量分段；条件显示为可移除小块，多个条件时提供清除全部 |
| 排序与视图 | 排序有明确字段与方向；列表／网格切换只改变呈现，不丢筛选、顺序、选择和页码 |
| 结果 | `Collection` 显示筛选后的总数；每项有标题、必要摘要、状态和清晰的打开动作 |
| 分页与选择 | `Pagination` 明确当前位置和边界；跨页选择用稳定 id 保存，批量操作显示已选总数；多选后的动作统一放在 `SelectionBar` |

搜索或筛选改变后回第 1 页；排序改变后也回第 1 页。分页、视图切换保留已有选择。若筛选隐藏了已选项目，明确显示包含隐藏项目的选择数量，并提供取消选择；不得悄悄扩大批量操作范围。是否跨页保留选择是产品决定，但同一集合应一致。

列表适合密集扫描文字，网格适合视觉识别和较长摘要。二者使用同样的信息层级、状态词和操作名称。卡片标题是查看按钮或链接，复选框负责选择；不要把整张含按钮的卡再包成一个按钮。

结果区域遵循[容器位置稳定原则](../principles/visual.md#容器位置不随-item-数量跳变)：数量变化保持顶部起点，少量卡片不整组居中；加载、空和失败状态替换区域内容。分页器需要固定在工作区底部时，由父布局预留结果高度，不按每页数量重新计算容器位置。

| 状态 | 呈现与恢复 |
|---|---|
| 首次加载 | 保留工具栏、给骨架和加载说明 |
| 刷新中 | 保留旧结果和条件，标记正在更新；禁止会重复执行的请求动作 |
| 尚无内容 | 说明集合为空，存在有效路径时提供创建或导入动作 |
| 无匹配结果 | 保留关键词与条件，提供清除筛选 |
| 请求失败 | 告知未更新，保留条件、输入和已有结果，给重试 |
| 有结果 | 显示筛选后总数，排序稳定；分页后必要时将焦点移到结果标题 |

## 表头说明

结果表格的每个表头与详情字段名同一写法：用 `TextTip` 包住列名，虚线下划线，悬停或点击显示这一列的含义（取自字段字典）。不在表格上方另写说明，也不给部分列加、部分列不加。

## 批量操作条

选中至少一项后，`SelectionBar` 浮在结果区底部，取消全部选择即消失；不选择时不出现，也不占位。它是一条极简的胶囊：浮层面与投影表达临时浮起，不加描边；左侧写「已选 N 项」和一个取消选择的图标按钮，一段短竖线之后放动作。

- 动作只放对当前选择有意义的：不满足条件的对象由业务逐条说明跳过原因，不把按钮整体禁用到让人猜。动作按钮用无底色的次按钮，最后一步或最常用的一个可用主按钮；超过三个动作时其余收进 `ActionMenu`。
- 已选项被筛选隐藏时，数量后写明「（N 项在筛选外）」，并保留取消选择；不得悄悄扩大批量范围。
- 位置粘在视口底部但仍在文档流里，最后一项能滚到它上方；与右下角派活入口同时出现时居中放置，互不遮挡。
- 结果区顶部只保留结果数量与排序，不再在顶部放第二套批量按钮。Esc 取消选择，焦点回到发起选择的位置。

示例：`showcase/react.tsx` 的 `BrowserDemo`，包含组合筛选、排序、列表／网格、跨页选择、详情抽屉与状态恢复。组件只负责呈现；请求、缓存、权限和批量操作交给业务代码。

筛选结果区顶部左侧显示匹配数量，右侧放排序。数量与排序属于结果层，不放在页面标题、面包屑或筛选组；有时间筛选时将其放在筛选组开头，其他条件并列。下拉全量项固定首位，仅写“全部”。

同一时间字段的排序统一复用 `SortMenu`：显示“更新时间”与方向图标，初始新到旧，点击或键盘激活切为旧到新，再次激活恢复。先对完整筛选结果排序，再分页；时间相同时用稳定 id 作次级排序。切方向回到第 1 页，保留筛选、视图与已选项。每条记录显示来源提供的更新时间，便于核对顺序。
