# 模板选用指南

模板只管骨架：一个应用由哪几栏组成、一个页面里的内容按什么顺序排。里面放什么组件见 `components/README.md`。

| 模板 | 什么时候用 | 结构 |
|---|---|---|
| 应用外壳 `.vx-app` | 桌面工作台类应用的整体框架 | 左栏导航（可收起）+ 对话（按需出现）+ 渲染区（浏览器式页签，可整体关闭）；各会话独立恢复页面状态，见[页面与对话](../patterns/page-chat-flow.md) |
| 页面 `.vx-page` | 渲染区里的一个功能页 | 页头 `.vx-pagehead`（任务与范围，说明按需）→ 要处理的 → 参考信息（收起）；以阅读为主、内容不宽时加 `--narrow` |
| 列表 + 详情 `.vx-split` | 左边挑一个对象，右边处理它（会话、项目、工单） | 左列深一档的面，右列详情；窄屏时上下排 |
| 引导页 `.vx-onboard-shell` + `.vx-onboard` | 首次进入、只需要回答几个问题 | 整屏铺开，每屏只问一件事；顶部进度，底部「上一步」和主按钮；不显示左栏和对话 |

页面里的布局工具（定义在 `components/css/base.css`）：
- 等宽并排用 `.vx-grid.vx-grid--2 / 3 / 4`（间隔 16px）。
- 上下排用 `.vx-stack`（16px），独立区块用 `.vx-stack--lg`（24px）。
- 一行里排几样用 `.vx-cluster`，需要把后面的推到最右时，中间放 `.vx-spacer`。

容器遵循[位置稳定原则](../principles/visual.md#容器位置不随-item-数量跳变)，按[页面任务选择视口框架](../patterns/page-composition.md#按任务选择视口框架)。

- 欢迎说明：外层 `.vx-onboard-shell` 在视口内平衡整组内容；内层 `.vx-onboard` 按头部、正文、动作自然排布，动作跟随正文。长内容自然滚动。
- 数量可变的分步选择：内层加 `.vx-onboard--fixed`，工作框高 `min(100dvh, 860px)`，外层定位；头与动作固定，正文独立滚动。切换步骤应重置正文滚动位置。内容数量只能改变内部排布，不能移动框架。
- 连续任务导览：`Guide variant="banner"` 自动测量说明区，`.vx-app` 扣除 `--vx-guide-space` 后保留真实工作空间。其他固定入口同步使用该偏移，见[功能导览](../patterns/guide.md)。
- 路线选择：`Dialog variant="stage"` 沿用模态语义，把标题、说明、选择和动作作为一组定位，动作不推到远离内容的屏幕边缘。

误用：
- 用模板解决某个组件的样式问题。
- 在页面里自己画分栏线（列表 + 详情靠面的明度差分开）。
- 引导页里放左栏或对话。

## 宽度与溢出

布局按可用宽度响应：1200px 内对话栏缩为 300px，空间不足时使用 `WorkspaceOverlay` 覆盖显示；列表加详情在渲染区 640px 内改为上下排。手机不保留图标栏，通过 `Tabs.leading` 入口打开实色导航抽屉。参考接入以 740px 视口切换导航、980px 切换为至多 420px 的覆盖对话，600px 内才铺满视口；使用 `useViewportQuery` 跟随缩放，桌面偏好与移动展开状态分开保存。

桌面手动折叠侧栏时图标保持同一中心线，非空分组以短线分隔；隐藏说明、组标题和临时项关闭按钮，关闭仍可从页签进入。账户只保留头像一个菜单热区，不显示三点。移动抽屉提供遮罩、焦点循环、Esc 与点击外部关闭；选择页面后关闭抽屉，对话里的页面跳转关闭覆盖面板，直接展示落点。

页签横向滚动，页面内部长表格局部横向滚动；长标题允许省略并保留完整可访问名称。关闭面板后焦点回到可见入口；只剩对话时恢复入口在对话头部。折叠导航保留按钮名称与悬停提示。
