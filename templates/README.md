# 模板选用指南

按页面的空间关系选模板。模板确定各区域的位置、阅读顺序和窄屏重排方式，区域内的控件见[组件选用指南](../components/README.md)。

| 模板 | 什么时候用 | 结构 |
|---|---|---|
| 应用外壳 `.vx-app` | 需要在多个工作区间导航、保留上下文 | 导航区与主工作区分开，辅助对话和页签按需使用。返回时恢复原上下文。[切换与恢复](../patterns/page-chat-flow.md) |
| 页面 `.vx-page` | 单页完成一项目标或阅读一组内容 | 页头说明当前对象与范围，正文先放判断所需的信息与操作。适合窄栏阅读时加 `--narrow`。 |
| 列表与详情 `.vx-split` | 在一组对象中选择并查看其中一项 | 宽容器并列呈现选择区与详情，窄容器上下重排。 |
| 门户入口 `.vx-portal` | 用户进入产品时同时需要辨认品牌和找到主入口 | 宽容器将品牌展示与可操作面板分开，窄容器为表单和焦点保留空间。 |
| 分步引导 `.vx-onboard-shell` + `.vx-onboard` | 需要按顺序完成多个决定 | 顶部显示进度，每步围绕一个决定，前进与返回紧邻该步内容。 |

页面里的布局工具（定义在 `components/css/base.css`）：
- 等宽并排用 `.vx-grid.vx-grid--2 / 3 / 4`（间隔 16px）。
- 上下排用 `.vx-stack`（16px），独立区块用 `.vx-stack--lg`（24px）。
- 一行里排几样用 `.vx-cluster`，需要把后面的推到最右时，中间放 `.vx-spacer`。

容器遵循[位置稳定原则](../principles/visual.md#容器位置不随-item-数量跳变)，按[页面任务选择视口框架](../patterns/page-composition.md#按任务选择视口框架)。

- 欢迎说明：外层 `.vx-onboard-shell` 在视口内平衡整组内容；内层 `.vx-onboard` 按头部、正文、动作自然排布，动作跟随正文。长内容自然滚动。
- 数量可变的分步选择：内层加 `.vx-onboard--fixed`，工作框高 `min(100dvh, 860px)`，外层定位；头与动作固定，正文独立滚动。切换步骤应重置正文滚动位置。内容数量只能改变内部排布，不能移动框架。
- 连续任务导览：`Guide variant="banner"` 自动测量说明区，`.vx-app` 扣除 `--vx-guide-space` 后保留真实工作空间。其他固定入口同步使用该偏移，见[功能导览](../patterns/guide.md)。
- 路线选择：`Dialog variant="stage"` 沿用模态语义，把标题、说明、选择和动作作为一组定位，动作不推到远离内容的屏幕边缘。

## 门户模板的布局与动效

外部入口需要先辨认产品、再开始操作时，可以使用门户模板。登录示例中，标题与表单同组，补充说明按需出现。字段用 `.vx-portal-fields` 组织，校验失败在相应字段旁说明如何修正。快捷登录账号仅用于演示。看板首屏可用 `.vx-portal-hero` 组合标题、指标与范围。

- 登录示例使用 `.vx-portal-field` 与 `.vx-portal-input` 将标签、输入与校验提示关联。聚焦行有焦点环，提交后在缺失项旁提示。宽屏用约六成宽度呈现品牌色，表单与说明共用辅助面，登录按钮使用动作色。窄屏保留顶部品牌色带，将其余高度交给表单。[按页面任务分配颜色](../principles/visual.md#按页面任务分配颜色)
- 首屏指标的单位紧跟数值，时间范围与筛选放在标题后。示例用 `DateFilter` 选择范围，`.vx-rise` 处理入场，`.vx-lift` 提示可以打开的内容卡。
- 需要背景纹理时，`PortalFeed` 用低对比的抽象卡片保留连续品牌底色。产品名使用 `.vx-portal-brand-name` 定位，加 `.vx-brand-panel` 取得成对的品牌底色与字色。登录示例使用 `marks={0}`，把鲜明的点缀留给提交。
- 动效只有两种：瀑布流慢速漂移（每列 56–86 秒一圈），以及内容首次出现时的上浮 `.vx-rise`（同组按 `--i` 错开 70ms）。不做视差、鼠标跟随或循环闪烁；减少动态效果时全部停住。
- 标题可用 4xl 到 display 的展示字号，数字用 `font-family-num`；其余文字仍按三级。
- 内部工作台不用这个模板。

误用：
- 用模板解决某个组件的样式问题。
- 在页面里自己画分栏线（列表 + 详情靠面的明度差分开）。
- 引导页里放左栏或对话。

## 宽度与溢出

将同一界面放入宽容器和窄容器，用键盘完成同一个操作，核对对象、结果和返回焦点。以门户登录为例，依次输入无效值、修正并提交，观察提示与主操作是否都在可达位置。[跨端保留任务](../patterns/page-composition.md#跨端保留任务)

布局按可用宽度响应：1200px 内对话栏缩为 300px，空间不足时使用 `WorkspaceOverlay` 覆盖显示；列表加详情在渲染区 640px 内改为上下排。手机不保留图标栏，通过 `Tabs.leading` 入口打开实色导航抽屉。参考接入通过 `useWorkspaceLayout` 测量工作区。可用宽度至多 740px 时导航用抽屉；导航展开时至多 960px、导航折叠时至多 740px 时对话用浮层。桌面展开偏好与窄区临时状态各自保存。

桌面手动折叠侧栏时图标保持同一中心线，非空分组以短线分隔；隐藏说明、组标题和临时项关闭按钮，关闭仍可从页签进入。账户只保留头像一个菜单热区，不显示三点。移动抽屉提供遮罩、焦点循环、Esc 与点击外部关闭；选择页面后关闭抽屉，对话里的页面跳转关闭覆盖面板，直接展示落点。

页签横向滚动，页面内部长表格局部横向滚动；长标题允许省略并保留完整可访问名称。关闭面板后焦点回到可见入口；只剩对话时恢复入口在对话头部。折叠导航保留按钮名称与悬停提示。
