# 模板选用指南

模板只管骨架：一个应用由哪几栏组成、一个页面里的内容按什么顺序排。里面放什么组件见 `components/README.md`。

| 模板 | 什么时候用 | 结构 |
|---|---|---|
| 应用外壳 `.vx-app` | 桌面工作台类应用的整体框架 | 左栏导航（可收起）+ 对话（按需出现）+ 渲染区（浏览器式页签）；右下角唯一的派活入口 `.vx-ask` |
| 页面 `.vx-page` | 渲染区里的一个功能页 | 页头 `.vx-pagehead`（标题 + 一句结论）→ 要处理的 → 参考信息（收起）；以阅读为主、内容不宽时加 `--narrow` |
| 列表 + 详情 `.vx-split` | 左边挑一个对象，右边处理它（会话、项目、工单） | 左列深一档的面，右列详情；窄屏时上下排 |
| 引导页 `.vx-onboard` | 首次进入、只需要回答几个问题 | 整屏铺开，每屏只问一件事；顶部进度，底部「上一步」和主按钮；不显示左栏和对话 |

页面里的布局工具（定义在 `components/css/base.css`）：
- 等宽并排用 `.vx-grid.vx-grid--2 / 3 / 4`（间隔 16px）。
- 上下排用 `.vx-stack`（16px），独立区块用 `.vx-stack--lg`（24px）。
- 一行里排几样用 `.vx-cluster`，需要把后面的推到最右时，中间放 `.vx-spacer`。

容器遵循[位置稳定原则](../principles/visual.md#容器位置不随-item-数量跳变)。引导页正文从顶部留白后的同一起点开始，切换不同数量的选项时不重新垂直居中；底部操作也需固定时加 `.vx-onboard--fixed`，正文独立滚动，最后一项可滚到操作区上方。需要稳定相邻区域的工作台，由父布局限定内容高度并提供内部滚动。

误用：
- 用模板解决某个组件的样式问题。
- 在页面里自己画分栏线（列表 + 详情靠面的明度差分开）。
- 引导页里放左栏或对话。

## 宽度与溢出

布局按容器宽度响应：1200px 内自动压缩左栏，720px 内对话以浮层覆盖，避免继续挤压内容；列表加详情在渲染区 640px 内改为上下排。外壳面向桌面，建议从 1024px 窗口验收；更窄或缩放后仍应能滚动与操作，移动端产品需另行验证。

自动压缩侧栏时收起说明和空状态文字，分组动作仍可用；账户头像与附加操作纵向排列，避免挤出窄栏。手动折叠的宿主可提供独立的图标入口。

页签横向滚动，页面内部长表格局部横向滚动；长标题允许省略并保留完整可访问名称。关闭对话后焦点回到派活入口，折叠导航保留按钮名称与悬停提示。
