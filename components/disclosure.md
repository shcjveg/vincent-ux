# 收起与展开

原型中反复出现的收纳方式包括分组、对象详情、编辑区、行内步骤和对话过程。按任务选结构，复用同一套文字、箭头、状态与键盘规则。侧栏折叠和工作区关闭属于[外壳模板](../templates/README.md)，不混入内容收纳。

## 按实际用途选用

| 用途 | 结构 | 收起时 | 展开时 |
|---|---|---|---|
| 一组设置、记录或次要依据 | `Fold` 默认 section | 名称；必要时给摘要；有集合才给带单位的 count | 原位置显示列表或明细，摘要若与明细重复则隐藏 |
| 对象行的补充详情 | `Fold variant="row"` | 对象标题＋必要说明，末尾数量／箭头 | 保留对象身份与必要说明，详情直接排在原承载面 |
| 一组待处理入口 | `Fold`＋`AttentionTitle`＋`.vx-todo-group` | 标题旁只计数一次，末尾箭头 | 展开导航清单；真正的 AI 反馈操作仍进入 `TaskCard` |
| 详情内的编辑区 | 受控 `Fold` | “补充…”／“编辑…”说明当前动作 | 字段与保存操作放在正文，保存成功再收起；草稿策略由宿主明确 |
| 对象旁的一小段操作步骤 | `Button`＋`.vx-chev` | 动作名＋向下箭头 | 动作名保持一致，箭头翻转；按钮通过 aria-controls 关联正文 |
| 对话里的执行过程 | `.vx-steps-toggle`＋`.vx-steps` | 过程名称、完成数／总数、末尾箭头 | 以 open ∨ running 决定可见；运行中保持展开，完成后沿用手动偏好；不能伪装成需要确认的待办 |

[可操作示例](../showcase/ComponentExamples.tsx) 按以上结构组织。示例使用通用资料与设置，产品中的字段、分组依据、排序优先级和请求仍由宿主负责。

## 结构与视觉

- Fold 整行头部是一个原生 button，不在头部嵌套链接、开关、菜单或按钮。设置开关、编辑、查看来源等交互放在展开正文。`side` 只放必要的非交互元信息，例如来源时间。
- 从左到右为 summary／description、可选 side、count 与箭头。分组标题若已用 `AttentionTitle` 计数，就不再传 count。数量表达集合，不用数量模拟状态或紧急程度。
- 默认分组头 13px 常规次文字；对象行标题 14px 半粗主文字，说明 13px 常规次文字。数量与箭头沿用说明层；不为“展开／收起”额外增加可见文字、胶囊或色块，读屏名称仍包含当前动作。
- 头部最小高度 40px，纵向内边距 8px；标题与说明间隔 4px，操作区内部间隔 8px，箭头 14px。数值以现有设计变量和 `.vx-fold*` 为准，不在使用方重新定义一套密度。
- 正文直接接在头部下方，继承当前承载面，不加一张卡或重底色。裸放页面的 Fold 与卡片内容共用 20px 缩进；已有卡片内边距时不重复添加外边距。
- 关闭时向下箭头，打开时旋转 180°。悬停只提高操作区辨识度，焦点使用独立焦点环；不同分组的开关互不影响。

## 状态与职责

默认保留已挂载正文，用 hidden 隐藏关闭内容，因此再次打开保留输入和子组件状态；隐藏正文不进入键盘顺序。Fold 只控制可见性，不主动清空、提交、持久化或取消请求。

- 普通依据与历史默认收起；需要立即处理的第一组、从别处定位的对象可由宿主默认展开。
- `defaultOpen` 只决定首次挂载状态。筛选、定位、保存等需要外部决定展开时，用 open／onOpenChange，不混用两套状态。
- 设置分组的短摘要只在收起时显示；对象行的身份说明展开后仍保留。不要为所有说明一律隐藏或一律常驻。
- 编辑区默认保留草稿。原型里“关闭即放弃未保存修改”的链接编辑属于宿主策略：打开时从已保存值初始化，保存成功才关闭，并在字段旁说明关闭的后果。不能把这种策略写进 Fold 的通用默认行为。
- 对话过程按 `open || running` 展开。运行中点击标题切换手动偏好，过程仍保持可见；结束后沿用该偏好，不清空 open 或强制收起。
- 多个分组各自独立开关，不擅自做成只能展开一个的手风琴。需要互斥时由宿主依据任务明确控制。

分组摘要的原型用法可直接写成：

```tsx
const [open, setOpen] = useState(false)
<Fold summary="内容检查" description={open ? undefined : summary}
  count={`${items.length} 条`} open={open} onOpenChange={setOpen}>
  <ul className="vx-rows">{items.map(renderItem)}</ul>
</Fold>
```

## 键盘与验证

Enter／Space 切换当前头部，aria-expanded 与正文可见性同步，aria-controls 指向正文。展开后焦点留在头部，用户按 Tab 进入正文；关闭不能留下可聚焦的隐藏控件。宿主主动关闭含焦点的编辑区时，恢复到其可见入口。

在浅深主题与窄屏检查：长标题和摘要换行、数量与箭头完整可见，关闭后重开保留状态，受控摘要不重复，保存／关闭策略明确，其他分组状态不被联动改变。对话过程另查进行中展开与完成后收起。
