# 面包屑与二级页

复用原型中“原待办页 → 历史已办 → 原待办页”的路径。面包屑表达当前页面在任务里的位置；工作区页签、应用分类和页内筛选保留在各自层级。

## 页头位置

历史等下钻页面使用 `Breadcrumbs headingLevel={2}` **替换原页头标题**，不是在标题下再叠一行路径。一级是可点击的原页面名称，斜线轻分隔，末项是当前页标题。两级路径已经能表达归属时，不再补“首页”、返回箭头、重复标题或数量。

- 父级使用 button 回调或有真实 href 的链接，沿用次文字色；悬停提高辨识度并出现下划线，键盘焦点保留。
- 当前项使用标题字重与主文字色，aria-current 为 page，不能再次点击。
- 整组沿用 `.vx-breadcrumbs--title` 的页头字号、字重和间距；无独立标题语义的普通路径省略 headingLevel。
- 日期、类型、处理结果等属于正文筛选组，不塞到路径里。结果数量归属于结果区，不放到面包屑或标题旁。
- 窄屏允许路径在分隔符附近自然换行，名称完整可读；不压缩字号，不以截断隐藏当前页身份。

## 原型中的历史流程

进入历史后保留当前应用与待办归属，不另造一组工作区页签。点击一级标题回到对应待办子集，而不是一律回经营首页或全局首页。

业务范围、类型等共同条件沿原页上下文保留；历史可以使用自己的日期字段与处理结果条件。组件只呈现路径，路由、参数恢复与焦点由宿主处理，不把历史专用筛选误带回待办。

历史没有记录时保留路径与 `EmptyState`，省去筛选和重复零计数。有记录时显示原处理快照；建议和行动锁定，对话入口保留，详见[历史二级页](../patterns/task-workspace.md#历史二级页)。

```tsx
<div className="vx-pagehead">
  {history ? <Breadcrumbs headingLevel={2} items={[
    {label: title, onClick: backToTasks},
    {label: '历史已办'},
  ]}/> : <h2>{title}</h2>}
</div>
```

## 键盘与状态

Tab 到可返回的父级，Enter／Space 触发按钮；有 href 的父级保留链接的原生行为。当前项不进入交互顺序。宿主切换页面后把焦点放到可见的路径入口、标题或返回位置，避免原按钮消失后焦点遗留在空白处。

[独立可操作示例](../showcase/NavigationExamples.tsx) 默认展示历史页头，可以返回、切换范围、重新进入历史，以及查看无历史记录状态。[浏览器回归](../tests/breadcrumbs.spec.ts) 检查唯一页头、当前页语义、键盘返回、范围保留、空态和窄屏。
