# 抽屉详情

在不离开当前页的前提下查看、编辑或处理一个对象。抽屉只承载一个对象；多对象比较、批量处理回到页面。外观与焦点行为由 `DetailDrawer`（基于 `Dialog variant="drawer"`）提供，正文只用三种零件：分区 `DrawerSection`、字段 `Property`、追加记录 `.vx-log`。

## 结构

```
DetailDrawer                    标题（对象名）＋ 关闭；底部一个编辑出口
  DrawerSection title status?   分区：标题 · 状态胶囊 · 行尾动作？
    .vx-props                   字段栅格
      Property …                名称（虚线说明）＋ 值或控件
    .vx-log？                   追加记录（有才出现）
  DrawerSection …
```

## 分区

- **按 MECE 切分**：按对象自身的业务环节分区，彼此不重叠、合起来完整。每个字段只出现在一个分区；一类待办只落在一个分区。不另设「待处理」「其他信息」之类的兜底分区。
- **每个分区都有标题**，放在左上角，13px 半粗主色。
- **红点**：当前账号在这个分区有待处理时，红点放在标题文字左上角（`attention`），处理完成后消失。红点不计数。
- **状态**：标题右侧紧跟系统推导出的状态，用 `.vx-tag` 胶囊；两个独立维度用两个胶囊，不合并。状态只在这里表达一次，不再作为字段重复。
- **行尾动作**：只放不属于任何字段的少量动作（例如重新采集、查看全部笔记），用 `size="sm"` 的幽灵按钮或 `.vx-link`。
- **分隔**：分区之间只有一种分隔：留白加一道 `line-faint` 极细线。不套卡片、不加底色、不用粗线；没有数据或当前账号看不到的分区整段不渲染。
- **极简收起**：标题行就是开关（`DrawerSection defaultOpen`）。收起时只留红点、标题、状态胶囊和一个低调箭头，行尾动作随内容一起隐藏。默认只展开第一个分区；带红点的分区总是展开，从待办进入时滚到该分区并短暂描边。收起不改变草稿，编辑中收起的字段照常保存。

## 字段

- **谁不可编辑**：只有三类字段永远不可编辑——由其他事实派生的计算字段（T+N 日期、汇总）、从关联对象继承的字段（在源对象里编辑）、系统记录的时间与凭证（领取时间、提报时间、核验截图）。其余字段对有权限的账号都可编辑；已经完成的处理轮次进入记录，不作为字段。
- **两种状态**：每个字段只有可编辑、不可编辑两种状态。两种状态都是「名称在上、值在下」，放在同一个两列栅格 `.vx-props` 里；切换时位置不变，只是值换成控件。
- **名称**：13px 中等字重次色，所有字段同一种样式。名称用 `TextTip` 的虚线下划线承载口径说明（取自字段字典），不在字段下方另写说明文字。
- **值**：13px 常规主色；空值统一为「—」，「未知」等业务口径按产品约定显示为文字。
- **计算字段**（由其他事实派生，例如 T+8 日期、累计次数）永远不可编辑，样式与同类型的普通字段完全一致，不加锁形图标或灰底。编辑会影响它的字段时，计算字段随草稿实时重算，代替「保存后会怎样」的说明。
- **一种数据类型只有一种样式**：

| 类型 | 不可编辑 | 可编辑 |
|---|---|---|
| 文本、数值 | 文字（数值用 `.vx-num`） | `.vx-input` |
| 长文本 | 文字，保留换行，`wide` | `.vx-textarea`，`wide` |
| 日期、日期时间 | 统一一种日期格式的文字 | `input[type=date]` / `datetime-local` |
| 单选枚举（含是／否） | 文字 | `.vx-select`；取值可由用户扩充的枚举（例如封面类型）用 `Select creatable`，下拉里直接新增 |
| 多选枚举 | 用「、」连接的文字，`wide` | `.vx-option-grid` 复选，`wide`；可扩充时末尾一个「新增」输入框 |
| 文本列表（可新增，例如关键词） | 用「、」连接的文字，`wide` | 可移除的 `.vx-chip` ＋ 末尾输入框回车添加，`wide` |
| 链接 | `<a>` / `.vx-link` | `.vx-input` |
| 图片 | `.vx-images` 缩略图 | `.vx-images` 带添加格与移除（单张不独占一行） |
| 关联对象 | 对象名称；需要跳转时用 `.vx-link` | `.vx-select` |

- 不在字段里使用 `.vx-tag`、单选按钮组、分段控件或开关；状态胶囊只属于分区标题行。

## 编辑出口与权限

- 整张抽屉只有一个出口，固定在底部：查看时是「编辑」，编辑时是「取消」＋「保存」（无改动时禁用）。当前账号没有任何可编辑字段时不出现。新建对象直接以编辑态打开，「取消」关闭抽屉。
- **谁能编辑**由宿主按对象逐字段给出，界面只按结果渲染：管理员可编辑全部非计算字段；其他账号持有某类待办，就能编辑这类待办对应的字段。业务前置状态仍然生效（例如申诉提交前不能判定）。
- 从待办进入时，抽屉直接以编辑态打开，滚动到带红点的分区并短暂描边。
- 一次保存只提交改动过的字段；某一组字段（例如复核结论与违规标签）需要一起填写时，在保存时逐项提示缺失，不提前禁用无关字段。保存成功后回到查看态，同类还有下一项时可直接切到下一项。
- 保存带版本号；对象已被他人更新时保留已填内容并提示刷新。编辑中关闭抽屉即放弃草稿。

## 追加记录

核验、补图、复核、改期这类只追加不覆盖的历史，作为所属分区里最后一个独占一行的只读字段（名称如「处理记录」，说明写清只追加不覆盖），值是一张带表头的小表格 `table.vx-log`：

- 列固定为「时间 · 事项 · 附图」，三列对齐；没有任何附图时不出附图列。
- 外框与行线都是 `line-faint` 极细线，表头浅底、12px 三级色；时间列 12px 次文字色、等宽数字。
- 附图用 28×36 的小缩略图，点开看原图。
- 按时间顺序排列；记录不可编辑，也不单独成分区。

## 文字只用三档

| 层级 | 用于 | 样式 |
|---|---|---|
| 抽屉标题 | `.vx-overlay-head` | 16px 半粗 |
| 分区标题、字段名称、值与正文 | `.vx-drawer-section-title` / `.vx-prop-label` / `.vx-prop-value` | 13px；分区标题半粗主色，名称中等次色，值常规主色 |
| 记录时间与元信息 | `.vx-log time` / `.vx-meta` | 12px 三级色 |

## 间距

| 位置 | 值 |
|---|---|
| 外缘、标题到正文、正文到动作 | 沿用 `.vx-overlay-*`：20 / 16 / 24px |
| 分区之间 | 上下各 24px，中间一道极细线 |
| 分区标题到内容、分区内各块 | 16px |
| 字段之间（含两列栅格） | 16px；名称到值 6px |

所有值来自 `.vx-drawer-section` / `.vx-props` / `.vx-log`，使用方不另写 margin。

## 误用

- 分区套卡片、加底色、用粗线；收起后还露出字段摘要或动作，或把带红点的分区默认收起。
- 单独设「待处理」分区，把同一字段在两个分区各写一次。
- 字段名称有的带下划线、有的换颜色或字号；字段下方写一行说明。
- 同一种类型用两种控件（有的单选用下拉、有的用单选按钮），或在字段值里放状态胶囊。
- 分区里自带「保存」按钮，和底部出口并存；底部出现两个以上主按钮。
